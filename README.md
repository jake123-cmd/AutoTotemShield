# Auto Totem Shield — Minecraft 26.1.2

Client-side Fabric mod.

Behaviour:
- Above 3 hearts: keep the shield in the offhand.
- At 3 hearts (6 HP) or below: swap shield for one Totem from inventory.
- If the Totem is consumed while still at/below 3 hearts: automatically equip another.
- Once above 3 hearts: restore the shield.
- No HUD, no toggle key, no config required.

Build online with GitHub Actions. Fabric 26.1 requires Java 25.
